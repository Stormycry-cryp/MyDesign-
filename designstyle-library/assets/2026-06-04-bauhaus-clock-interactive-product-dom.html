Frequently asked questions

What makes Bauhaus Clock different from other screensavers?

Bauhaus Clock is the most elegant clock screensaver for Mac which combines precision engineering with stunning visual design. Every element, from clock numerals to movement types, is meticulously crafted to deliver the best clock screensaver experience on a Mac.

It replicates authentic watch mechanics with three movement options: Quartz (precise 1Hz tick), Mechanical (smooth 4Hz sweep at 28,800 beats per hour), and Digital (continuous motion). Features 13 customizable dials with day/night themes, works flawlessly on all Macs (Apple Silicon and Intel) running macOS 13 (Ventura) or later, and includes lifetime updates with your single purchase.

If you value quality and design, this is the clock screensaver for Mac users who appreciate true craftsmanship.

How do I install the Bauhaus Clock screensaver on Mac?

Installing Bauhaus Clock on your Mac is easy:

  1. Download the Bauhaus Clock Installer and double-click it to mount.

  2. Double-click 'Install Bauhaus Clock'.

  3. The installer automatically installs Bauhaus Clock and opens Screen Saver settings.

  4. Select 'Bauhaus Clock' from the list.

If System Settings doesn't open automatically, you can find Screen Saver settings here:

  • On macOS 26 Tahoe: Settings → Wallpaper → Screen Saver

  • On macOS 13–15: System Settings → Screen Saver

The screensaver is signed and notarized by Apple, so installation is safe and automatic.

Which macOS versions and Macs are supported?

Bauhaus Clock is optimized for macOS 13 (Ventura) and later, and runs on both Apple Silicon and Intel Macs. It's designed to work flawlessly on all Mac displays and external monitors, with perfect scaling and crisp visuals at any resolution.

Does Bauhaus Clock cause screen burn-in on OLED displays?

No, Bauhaus Clock is completely safe for OLED screens. It includes intelligent burn-in protection designed specifically for displays like the MacBook Pro Liquid Retina XDR screen.

The screensaver uses smart algorithms that subtly shift the clock position to prevent any static elements from staying in one place too long. This makes it safe for extended use on MacBook Pro XDR displays and external OLED monitors.

While we've built in comprehensive protection, you're responsible for managing your display settings appropriately.

What can I customize in Bauhaus Clock?

Bauhaus Clock offers extensive customization:

Clock Dials: 16 colors including White, Turquoise, Glacier, Ocean, Tennis, Signal Blue, Salmon, Yellow, Beige, Pistachio, Lavender, Rose, Sky Blue, Cream, Slate and Noir.

Themes: Day and Night modes with automatic switching based on your system theme. Night lume colors include Red, Amber, Lavender, Rose, Seafoam, Sky, Swiss BGW9, Peach, Tritium Green, Aqua, Yellow, Lime, Ice Blue, and White.

Movement Types:

  • Quartz: 1Hz precise tick

  • Mechanical: 4Hz smooth sweep with 28,800 beats per hour

  • Digital: Smooth continuous motion

Size Options: Classic or Compact

How do I uninstall or update Bauhaus Clock?

To uninstall the Bauhaus Clock screensaver:

  1. Go to System Settings → Screen Saver (On macOS 26 Tahoe: Settings → Wallpaper → Screen Saver).

  2. Right-click on 'Bauhaus Clock'.

  3. Select 'Delete' or 'Show in Finder' and then 'Delete'

To update to the latest Bauhaus Clock:

  1. Log into gumroad.com/library or https://polar.sh/atilladesign/portal

  2. Download the latest Bauhaus Clock files.

  3. Install.

Having issues updating to the latest Bauhaus Clock?

Follow these steps if you're running into any issues running Bauhaus Clock or updating to the latest version:

  1. Download the latest installer from gumroad.com/library

  2. Run the installer.

The installer removes any previous version, cleans Screen Saver preferences, and installs the latest version in one go.

A note on macOS Tahoe
In rare cases, the 'Options…' menu in Screen Saver settings may not open. If this happens, quit System Settings completely and reopen it. No need to restart your Mac.
This is a known Apple bug in macOS Tahoe, and we hope they fix it soon.
