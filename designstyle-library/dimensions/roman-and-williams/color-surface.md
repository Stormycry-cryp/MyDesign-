# Color And Surface

## Observed
- Color/material:
  - Observed text colors: dark charcoal or near-black over cream surfaces
  - Observed backgrounds: cream header and page shell, muted photographic browns, grays, and burgundy street-sign tones
  - UI shell colors vs asset-driven colors: the shell is warm-neutral; the images provide almost all color interest
- Surface grammar:
  - Surface/background system: warm off-white shell against soft photographic surfaces
  - Borders/dividers/radii: nearly no visible border language in the accepted viewport
  - Shadow/depth/material: flat interface surfaces; material richness is expressed through image texture and typography
  - Button/input/control density: low in the first viewport despite the commerce shell
  - Icon/illustration stroke style: minimal utility icons for account/cart/search
- Visual color:
  - Layout: thin top bar, large media hero, lower-left serif headline block, and a secondary image section entering below
  - Typography: fine serif display for the headline with understated sans navigation
  - Color: cream shell, muted city/street photography, soft charcoal text, restrained burgundy and stone tones from the image
  - Density: medium-low; the navigation is compact while the media and headline dominate
  - Shape: flat rectangles, no pill buttons, no ornamental chrome in the first viewport
  - Shadow/depth: little to no shadow; depth comes from photography and image blur

## Inference
- Borrow:
  - Borrow the restraint of the header and the confidence of letting imagery and serif copy do the persuasion.
  - Borrow the mix of design-practice storytelling with a commerce-capable shell.
  - Borrow the warm-neutral palette and low-contrast sophistication.
