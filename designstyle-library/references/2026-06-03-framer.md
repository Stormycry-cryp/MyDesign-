# Style Reference: Framer

## Essence
A creator-tool style that sells speed and polish through live-looking pages, template grids, motion previews, and direct manipulation cues. The reusable idea is showing that the output can be beautiful before explaining how the editor works.

## When To Use
- Website builders, template marketplaces, creator tools, portfolio products, and AI-assisted design tools.
- Pages where users choose based on perceived output quality and speed-to-publish.
- Feature education that can show before/after, variants, templates, and animations.

## When Not To Use
- Data-heavy admin systems where template glamour distracts from task clarity.
- Highly serious B2B workflows that need proof over expressiveness.
- Products without polished example outputs.

## Visual System
- Layout: Hero framed around output examples, template grids, interactive-looking previews, and segmented feature bands.
- Typography: Clean confident sans, concise claims, creator-friendly language.
- Color: Modern neutrals with bright accent moments; color often comes from showcased templates.
- Density: Medium-high in galleries, lower in hero/feature statements.
- Shape: Rounded preview frames, browser windows, tool panels, template thumbnails.
- Shadow/depth: Preview cards use soft elevation; editor chrome stays sharp.

## Assets
- Image style: Website screenshots, template thumbnails, animation previews, editor panels.
- Illustration/icon style: Product icons and small builder metaphors, not decorative mascot art.
- Texture/pattern: Subtle grids, stage/canvas backgrounds, preview surfaces.
- Likely sources or production method: Real templates, rendered site thumbnails, short video/GIF loops, editor screenshots.

## Motion
- Page transitions: Smooth and modern; product should feel fast.
- Micro-interactions: Hover previews, template reveal, drag/resize cues, publish/check states.
- Scroll/entrance behavior: Gallery items can stagger; demos can scrub or switch states.
- Timing/easing: Polished 180-300ms, occasional spring for direct manipulation.

## Interaction And Components
- Navigation: Product, templates, resources, pricing, enterprise paths.
- Buttons/links: Clear start/build/preview CTAs; creator tools benefit from immediate trial links.
- Cards/sections: Template cards need stable aspect ratios and useful metadata.
- Forms/inputs: Search/filter for templates; onboarding URL/project name input.
- Feedback states: Publishing, preview loading, invalid domain, template selected states.

## Implementation Notes
- CSS/layout primitives: Responsive thumbnail grids, aspect-ratio cards, sticky preview panels, CSS transforms for hover previews.
- Token ideas: Preview radius, canvas background, accent CTA, template metadata scale.
- Libraries or techniques: Framer Motion fits this category; lazy image loading and video thumbnails are important.
- Performance/accessibility concerns: Many thumbnails can hurt performance; reserve motion for visible previews and support keyboard navigation.

## Borrow
- Let example outputs do the selling.
- Make templates and previews feel interactive even in static marketing contexts.
- Use motion to communicate direct manipulation.

## Avoid Copying
- Do not hide product limitations behind beautiful templates.
- Avoid gallery chaos without filters or hierarchy.
- Do not use motion loops that make reading difficult.
