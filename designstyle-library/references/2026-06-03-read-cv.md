# Style Reference: Read.cv

## Essence
A minimal social-profile style that treats people, work history, writing, and links as quiet editorial objects. The reusable idea is respectful presence: profiles feel authored, scannable, and low-pressure.

## When To Use
- Portfolio networks, AI-native community profiles, personal pages, recruiting surfaces, collaborator directories.
- Products where identity and work samples should be browsed with care.
- Interfaces that need to feel quieter and more mature than generic social feeds.

## When Not To Use
- Sales-led landing pages requiring strong persuasion and CTA repetition.
- Entertainment products needing dramatic media and emotion.
- Dense operational dashboards where profile elegance is secondary.

## Visual System
- Layout: Profile-first pages, editorial lists, generous margins, compact metadata, simple feed/detail structures.
- Typography: Clean readable sans, subtle hierarchy, profile names and role summaries carry weight.
- Color: Neutral, low-saturation, content-first; color appears through avatars/work thumbnails.
- Density: Medium; lists are scannable but not cramped.
- Shape: Soft profile cards, avatars, link rows, project thumbnails.
- Shadow/depth: Very little; borders and spacing separate content.

## Assets
- Image style: Avatars, project thumbnails, screenshots, personal/work artifacts.
- Illustration/icon style: Minimal utility icons; avoid mascot energy.
- Texture/pattern: None or paper-like editorial quietness.
- Likely sources or production method: User-uploaded media, generated thumbnails, link previews, profile metadata.

## Motion
- Page transitions: Simple continuity between list/profile/detail.
- Micro-interactions: Follow/save/contact hover states, link preview, subtle row highlights.
- Scroll/entrance behavior: Feed/list should stay stable; avoid distracting reveals.
- Timing/easing: Fast and soft, 120-200ms.

## Interaction And Components
- Navigation: Search/discover/profile/settings paths should be understated but findable.
- Buttons/links: Contact/follow/link buttons must be visually quiet yet obvious.
- Cards/sections: Profile and project cards need stable image ratios and metadata hierarchy.
- Forms/inputs: Profile editing, link adding, search, invite flows.
- Feedback states: Empty profile, private/unlisted, upload progress, unavailable link preview.

- Token ideas: Quiet border, profile radius, metadata muted text, avatar sizes.
- Libraries or techniques: Link preview extraction, image upload/cropping, search indexing.
- Performance/accessibility concerns: User-generated media needs placeholders, alt text prompts, and robust empty states.

## Borrow
- Let identity and work samples breathe.
- Use low-pressure social mechanics for thoughtful community products.
- Prefer authored profiles over engagement-heavy feed chrome.

## Avoid Copying
- Do not make community feel so quiet that actions disappear.
- Avoid copying profile layouts without considering privacy and moderation.
- Do not use this style for products that need immediate conversion pressure.
