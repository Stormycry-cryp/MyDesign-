# v0.1.0

Date: 2026-06-03

Initial release of DesignStyle.

## Included

- `add-designstyle` skill upgraded for high-resolution reference capture.
- `use-designstyle` skill upgraded for dimension-based multi-reference composition.
- Local designstyle library with 20 references.
- Beauty/skincare cold-start batch with 10 scene-fit references:
  - Diptyque
  - Typology
  - Augustinus Bader
  - True Botanicals
  - Nécessaire
  - La Mer
  - Osea Malibu
  - Flamingo Estate
  - Monastery
  - Amala Beauty

## Evidence Improvements

- Layered tags for style, structure, motion, and code.
- First viewport geometry and dimension/ratio system.
- Typography, color/material, asset, component, and interaction-state decomposition.
- Public CSS/JS motion probe output.
- Exact motion parameters such as duration, easing, transform functions, keyframes, carousel hints, and reduced-motion evidence where available.

## Boundary

Motion-relevant snippets and parameters are preserved, but full proprietary CSS/JS is not copied into the library.
