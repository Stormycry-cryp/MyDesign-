# v0.2.0

Date: 2026-06-04

Progressive-disclosure release for DesignStyle.

## Included

- Added `skills/designstyle` as the L0 router for add, use, and add-then-use workflows.
- Upgraded `add-designstyle` so full references are followed by generated L1 cards and L2 dimension summaries.
- Upgraded `use-designstyle` so retrieval defaults to L1 cards, drills into selected L2 dimensions, and opens L3 full references only when needed.
- Added progressive schema, templates, generator, validator, and standard-library tests.
- Replaced the older weak-format reference set with 53 validated UI references.
- Generated 53 L1 cards and 371 L2 dimension summaries.

## Evidence Layers

- L1 cards: `designstyle-library/indexes/cards/*.json`
- L2 dimensions: `designstyle-library/dimensions/<slug>/*.md`
- L3 full references: `designstyle-library/references/*.md`
- L4 raw evidence: screenshots, DOM/resource captures, and asset clues

## Verification

Fresh local checks before release:

- `validate_references.py --library designstyle-library --json`: 53 total, 53 valid, 0 invalid.
- `build_progressive_reference.py --library designstyle-library --all --dry-run`: 53 cards and 371 dimensions planned.
- `build_progressive_reference.py --library designstyle-library --all`: 53 cards and 371 dimensions written idempotently.
- `validate_progressive_library.py --library designstyle-library --json`: 53 cards, 0 invalid, 0 errors.
- `search_references.py "hardware product minimal wearable landing page" --library designstyle-library --explain-selection`: hardware/product references rank above generic SaaS landing-page references.

## Boundary

The library still avoids storing full proprietary CSS/JS. Motion/code evidence is limited to resource URLs, short motion-relevant snippets, exact useful parameters, and implementation interpretation.
