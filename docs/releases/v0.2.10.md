# v0.2.10

Date: 2026-06-14

## Summary

v0.2.10 adds a mechanical validator for `use-designstyle` direction plans.

This closes the remaining loophole after v0.2.9: an agent could write a stronger-looking plan, but still omit the original-site inspection log, implementation mapping, side-by-side reference workbench, or screenshot QA evidence. The new validator makes those omissions fail before build work starts.

## Changes

- Added `skills/use-designstyle/scripts/validate_direction_plan.py`.
- Added unit tests for the validator:
  - incomplete plans are rejected when they lack reference workbench, implementation mapping, and screenshot QA
  - complete reference-fidelity plans pass
- Updated `use-designstyle` so agents must run:

```bash
python3 ~/.codex/skills/use-designstyle/scripts/validate_direction_plan.py work/designstyle-direction-plan.md
```

- The validator checks for:
  - Reference-Led Execution Contract
  - Original-Site Inspection Log
  - side-by-side reference workbench
  - Style Fidelity Contract
  - Implementation Mapping with concrete CSS/layout/motion constraints
  - Page Logic And Information Hierarchy Mapping
  - Typography And Font Mapping
  - Final QA Checklist with screenshot paths
  - at least 3 visible similarities and 2 intentional differences

## Verification

Validated locally before release:

- `python3 -m unittest skills.use-designstyle.tests.test_direction_plan_validator -q`: 2 tests passed.
- `python3 -m py_compile skills/use-designstyle/scripts/*.py install.py`: passed.
- `python3 skills/use-designstyle/scripts/run_search_regression.py --library designstyle-library`: 15 queries, top3 rate 1.0, wrong top1 0, passed true.
- `validate_direction_plan.py` rejects an incomplete plan and accepts a complete reference-fidelity plan.

## Boundary

- This release validates the direction plan shape and evidence markers; it does not visually score screenshots by itself.
- Final visual comparison still belongs to screenshot QA, `compare_against_reference.py`, browser screenshots, and human/design judgment.
