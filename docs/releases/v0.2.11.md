# v0.2.11

Date: 2026-06-14

## Summary

v0.2.11 wires the v0.2.10 direction-plan validator into blind E2E.

The point is to make the regression suite obey the same rules as future agents: a generated `designstyle-direction-plan.md` cannot skip the reference-led contract, original-site inspection log, implementation mapping, page logic mapping, typography mapping, or screenshot QA and still pass.

## Changes

- Updated `skills/use-designstyle/scripts/run_blind_e2e.py`:
  - generated plans now include the full v0.2.10 reference-fidelity sections
  - generated plans include side-by-side reference workbench language
  - generated plans map reference mechanics to CSS/layout/motion constraints
  - generated plans include final screenshot QA paths and visible-similarity / intentional-difference requirements
  - `run_case()` calls `validate_direction_plan.py` before screenshots and comparison work continue
- Expanded `skills/use-designstyle/tests/test_direction_plan_validator.py`:
  - validator still rejects incomplete plans
  - validator still accepts complete plans
  - blind E2E generated plans must pass validator
