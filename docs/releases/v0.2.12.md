# v0.2.12

Date: 2026-06-14

## Summary

v0.2.12 makes AI/AICG artist portfolio retrieval concrete instead of hopeful.

The published library now includes two AI/AICG portfolio references, and search regression has an explicit `expected_top1` guard so the AI artist portfolio query must return `roope-rainisto` first. This protects `use-designstyle` from drifting toward generic portfolio pages, dashboards, or enterprise AI sites when the requested scene is an AI/AICG artist portfolio.

## Changes

- Added active references:
  - `roope-rainisto`
  - `an-ai-portfolio-in-the-cosmos`
- Published their L1 cards, L2 dimensions, screenshots, component-style JSON, and design-system packs.
- Updated `search_references.py`:
  - expands low-signal generic page terms such as `portfolio`, `project`, `website`, and `typography`
  - adds high-signal topic token scoring for vertical terms such as `ai`, `artist`, and `aicg`
  - keeps scene/category fit ahead of generic motion/page-word matches
- Updated `run_search_regression.py`:
  - supports `expected_top1`
  - fails when a case requires a specific top result and search returns another slug first
- Added regression case `portfolio-ai-artist-aicg`.
