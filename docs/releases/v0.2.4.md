# v0.2.4

Date: 2026-06-04

## Summary

v0.2.4 upgrades DesignStyle from design-system backfill to code-informed component-system retention.

The active library now contains 76 validated references. One recrawled reference (`arc-browser-product-site`) was excluded because the live page captured a Cloudflare/security challenge instead of the intended product UI. The excluded evidence is preserved under `designstyle-library/references-excluded/blocked/`, `assets-excluded/blocked/`, and `screenshots-excluded/blocked/` but does not count toward active retrieval, active design systems, or quality scoring.

## Changes

- Added live-DOM computed component capture to `add-designstyle`:
  - Playwright + real Chrome rendering.
  - `getComputedStyle` and geometry capture for navigation, buttons, cards, forms, icons, and sections.
  - Hover/focus delta sampling where observable.
  - Structured raw evidence in `assets/YYYY-MM-DD-<slug>-component-styles.json`.
- Added batch recrawl tooling for existing references with component-code quality gates.
- Updated design-system generation so `component-styles.md` and `tokens.json` prioritize computed component JSON before Markdown fallback summaries.
- Added blocked-page hygiene:
  - Cloudflare/security challenge pages fail component-code capture.
  - Challenge evidence is excluded from active references and preserved separately.
- Added raw evidence hygiene:
  - Abnormal scientific-notation px values such as `3.35544e+07px` are filtered from raw JSON and generated design-system artifacts.
  - Existing active reference and dimension Markdown were also cleaned so L2/L3 text evidence no longer carries scientific-notation px noise.
  - Valid common CSS values such as `9999px` pill radii are preserved.
- Updated `use-designstyle` guidance to check raw component JSON when implementation-grade component styling is needed.
