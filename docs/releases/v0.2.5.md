# v0.2.5

Date: 2026-06-04

## Summary

v0.2.5 slims the default DesignStyle library by removing raw DOM snapshots from the committed active library while preserving the evidence layers that remain useful for retrieval and design implementation.

Active references still retain one screenshot per reference, one computed component-style JSON file per reference, and one design-system pack per reference. Raw DOM is now treated as L4 on-demand evidence: capture it to external temp storage during add/refresh workflows, then extract only the needed facts back into references, dimensions, and design-system artifacts.

## Changes

- Removed active raw DOM snapshots from `designstyle-library/assets/`.
- Removed duplicate older DOM snapshots and an unreviewed candidate batch directory from the committed library.
- Removed candidate screenshots that were not attached to active references.
- Kept all active component-style evidence in `designstyle-library/assets/*-component-styles.json`.
- Kept all active screenshots in `designstyle-library/screenshots/`.
- Updated `add-designstyle`, `use-designstyle`, and router guidance so raw DOM is stored outside the project and recaptured from the source URL only when L0-L3 plus retained component evidence are insufficient.
- Updated capture tooling so raw DOM writes to `/tmp/designstyle-raw-evidence/` instead of the project library.
