# v0.2.7

Date: 2026-06-08

## Summary

v0.2.7 publishes the DesignStyle evidence-loop upgrade on top of the existing remote v0.2.6 HITL and plan-led workflow.

The release keeps the remote `bunkhouse` reference, syncs the packaged repository to the current live local skill/library state, and upgrades `designstyle`, `add-designstyle`, and `use-designstyle` so Add and Use now form a verifiable loop:

```text
designstyle routes and enforces the shared contract
  -> add-designstyle captures future-use-ready evidence
  -> use-designstyle retrieves evidence by scene and role
  -> use-designstyle reports partial/weak coverage as add-designstyle backlog
```

## Changes

- Preserved the v0.2.6 `use-designstyle` upfront HITL gate and plan-led iteration contract.
- Added `designstyle` Shared Contract and Handoff Rules:
  - routing reason
  - evidence layers read or generated
  - scene/page fit
  - required dimensions
  - missing evidence
  - reuse boundary
  - next handoff
- Added `add-designstyle` Use-Readiness Gate and Use Readiness output.
- Added `use-designstyle` Coverage Strength and Add-Designstyle Backlog.
- Strengthened `search_references.py`:
  - page scope and category fit now outrank broad style/motion words
  - motion/code evidence is gated by scene/page fit
  - `--explain-selection` reports selected reason, rejected reason, category/page fit, and coverage hints
- Strengthened validators:
  - L1 progressive cards require `missing_evidence` and `component_json_path`
  - active cards cannot point at excluded assets or challenge-page evidence
  - `validate_references.py` now returns non-zero when references are invalid
- Added regression tests for the shared contract, Use-readiness, Coverage/Backlog flow, search ranking, explain output, and validator strictness.
- Regenerated the active L1/L2/design-system retrieval layer for 92 active references.

## Known L3 Backfill Gap

`validate_references.py` is intentionally stricter in v0.2.7. It now requires complete L3 references to include:

- `Reference Text And Copy Grammar`
- `Style Tokens And Surface Grammar`

The current historical L3 reference files predate that stricter schema, so `validate_references.py --json` reports 92 invalid references. This is a real content backfill gap, not a hidden validation pass.

The generated active retrieval layer is valid:

- L1 cards
- L2 dimensions
- design-system packs
- retained component-style JSON

Use `validate_progressive_library.py` as the current active-readiness gate until the L3 Markdown backfill is complete.
