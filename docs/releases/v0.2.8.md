# v0.2.8

Date: 2026-06-12

## Summary

v0.2.8 records the progressive motion, Style DNA, Apply Pack, and use-side comparison upgrade for the DesignStyle skill suite.

This snapshot closes the v0.2.7 L3 backfill gap and makes the Add -> Use loop implementation-grade:

```text
add-designstyle captures structured evidence
  -> generated L1/L2/L3/design-system layers stay validateable
  -> use-designstyle retrieves by scene and dimension
  -> build work imports Apply Packs and compares output against references
```

## Changes

- Added structured motion extraction and backfill:
  - per-reference `motion.json`
  - selector role, trigger, property, duration, delay, easing, reduced-motion status, source, and human description fields
  - complete reusable entries under `items`
  - incomplete parsed evidence under `omitted_incomplete` with explicit `missing_fields`
- Rebuilt L2 `motion-code.md` as table-first motion summaries, with snippets demoted to appendix evidence.
- Added measurable Style DNA to L1 cards for retrieval and generated-vs-reference comparison.
- Split design tokens into evidence and apply layers, then generated Apply Pack files:
  - `variables.css`
  - `tailwind.theme.json`
  - `motion-presets.css`
- Strengthened retained-artifact hygiene:
  - truncated CSS walls are blocked from active artifacts
  - autofill, consent, cookie, and captcha style noise are blocked from active artifacts
  - abnormal browser-computed scientific-notation `px` values remain filtered
- Upgraded `use-designstyle` retrieval:
  - category and page-scope hard filtering before dimension scoring
  - structured `--need` queries such as `motion:L2,palette:dark,scene:dashboard`
  - borrowable and non-borrowable dimension output per candidate
- Added use-side comparison evidence:
  - Apply Pack section in comparison reports
  - generated/reference screenshot paths
  - DNA checklist
  - iteration log
  - probe-based aesthetic fit scoring
- Added blind E2E fixtures for dashboard, luxury landing, and docs-site scenes.

## Boundary

- Full proprietary CSS/JS is not stored.
- Parsed values that cannot be proven stay marked as missing.
- Incomplete motion evidence stays visible under `omitted_incomplete`; it is not promoted into presets.
- Backfill failures must remain partial and explicit; old-format artifacts must not be presented as v0.2.8-ready evidence.
