# v0.2.9

Date: 2026-06-14

## Summary

v0.2.9 strengthens `use-designstyle` so agents must use references as implementation evidence, not mood labels.

The main change is a stricter use-side fidelity loop:

```text
retrieve scene-fit references
  -> inspect the live original site or retained evidence
  -> keep a side-by-side reference workbench while building
  -> map reference mechanics into CSS/layout/motion constraints
  -> verify screenshots against the selected references
```

## Changes

- Added a Reference-Led Execution Contract before search, planning, or implementation:
  - goal
  - method
  - acceptance criteria
  - required reference dimensions
  - missing evidence rules
- Added an Original-Site Inspection Gate:
  - open or recapture live `source_url` references when reachable
  - inspect desktop, mobile, deeper sections, hover/focus, motion, fonts, and computed styles when relevant
  - cite retained screenshots, component JSON, or design-system files when the live site is blocked
- Added a side-by-side reference workbench requirement during implementation.
- Added a Style Fidelity Contract before build work:
  - each primary reference must yield concrete mechanics for layout, section sequence, grid/ratio, type, surface, content, components, and motion
  - default patterns such as generic centered hero plus cards must be named and forbidden when they contradict the reference
- Expanded `work/designstyle-direction-plan.md` with:
  - original-site inspection log
  - style fidelity contract
  - implementation mapping
  - page logic and hierarchy mapping
  - typography and font mapping
  - screenshot structural QA
- Strengthened final audit:
  - compare final desktop screenshot against retained reference screenshots
  - name at least 3 visible similarities and 2 intentional differences
  - confirm page logic, hierarchy, typography, motion, and component states against the inspection log
- Updated the `designstyle` router so complete visual-system tasks require the new use-side fidelity dimensions.
- Added a regression prompt for the failure mode where an AI artist portfolio becomes a generic centered hero plus cards layout.

## Boundary

- This release changes how references are used; it does not add new active library references.
- The default active library count remains 95 references.
- Missing reference evidence must remain marked as missing. Agents must not infer fonts, motion parameters, component states, or page logic from adjacent vibes.
